# doughnut_workshop

Welcome to the resources repository for The Doughnut Workshop!

This educational workshop introduces Kate Raworth's Doughnut Economics framework to elementary school students through cooperative learning activities.

## Educational resources

The following  materials are available in French:

Séance 1 

Guide — le guide explique les différentes étapes à suivre pour créer votre propre matériel pour la première séance de l'atelier du doughnut.

Matériel — les documents à imprimer et utiliser pour la séance 1

Séance 2

Guide — le guide explique les différentes étapes à suivre pour créer votre propre matériel pour la deuxième séance de l'atelier du doughnut.

Matériel — les documents à imprimer et utiliser pour la séance 2

*Nous vous conseillons de bien préparer la séance longtemps en avance, et de commencer par lire le guide de chaque séance*

## How to download the materials

Click on a folder to browse the available resources. You can download individual files or download the entire repository by selecting Code → Download ZIP.
